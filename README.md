# Toonflix (프로젝트 제목)

> 웹툰을 편리하게 감상할 수 있는 Flutter 기반의 웹툰 앱입니다. (프로젝트 한 줄 설명)

##  주요 기능

*   **오늘의 웹툰**: 요일별로 업데이트되는 최신 웹툰 목록을 제공합니다.
*   **에피소드 보기**: 선택한 웹툰의 전체 에피소드 목록을 확인하고, 원하는 회차를 볼 수 있습니다.
*   **상세 정보**: 각 웹툰의 장르, 연령 정보 등 상세한 정보를 제공합니다.
*   **좋아요** : 마음에 드는 웹툰에 좋아요를 눌러 더욱 편하게 웹툰을 볼 수 있습니다.

## 기술 스택

*   **Framework**: Flutter
*   **Language**: Dart
*   **State Management**: GetX
*   **HTTP Client**: Dio
*   **Data Source**: Naver Webtoon API

## 설치 및 실행

1.  **저장소 복제**:
    ```
    git clone https://github.com/chubeloop/toonflix_.git
    ```
2.  **프로젝트 폴더로 이동**:
    ```
    cd toonflix_
    ```
3.  **Flutter 패키지 설치**:
    ```
    flutter pub get
    ```
4.  **앱 실행**:
    ```
    flutter run
    ```

## 개발 동기

Flutter와 GetX 상태 관리를 학습하고, 실제 API를 연동하여 웹툰 앱을 만들어보는 것을 목표로 이 프로젝트를 시작하게 되었습니다.
